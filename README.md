## Run locally
Install Node.js, open this folder in a terminal, then run:

```bash
npm install
npm run dev
```

## Build for GitHub Pages
```bash
npm run build
```

Upload the contents of this project to a new GitHub repository. In repository Settings → Pages, choose GitHub Actions or configure Pages to publish the `dist` folder using a suitable workflow. The Vite config uses relative asset paths (`base: './'`) so it can work from a project subpath.

This is an independent implementation based on the general Week 11 topics. Update it if your instructor's requirements differ.
